# Aprendendo Python

Exercicio introdutorio em Python para praticar `for`, manipulacao de strings e entrada de dados pelo terminal.

## Visao geral

Este repositorio documenta um estudo basico de Python. O script recebe uma palavra informada pelo usuario, converte o texto para letras maiusculas e percorre cada caractere usando um loop `for`.

## Problema resolvido

O projeto ajuda a entender como strings podem ser percorridas caractere por caractere e como transformar dados de entrada antes de exibi-los.

## Principais funcionalidades

- Entrada de texto pelo terminal.
- Conversao de palavra para letras maiusculas.
- Percurso de caracteres com `for`.
- Impressao formatada dos caracteres.

## Como funciona

O usuario digita uma palavra. O programa transforma essa palavra em maiusculas e imprime cada letra em sequencia, demonstrando a iteracao sobre strings.

## Tecnologias utilizadas

- Python
- Linha de comando
- Poetry identificado por `pyproject.toml`

## Arquitetura

Projeto simples com um unico script principal.

## Estrutura do projeto

- `main.py`: script com o exercicio de loop e string.
- `pyproject.toml`: configuracao Python/Poetry.
- `poetry.lock`: lockfile de dependencias.
- `replit.nix` e `.replit`: arquivos de ambiente Replit.
- `venv/`: ambiente virtual versionado no repositorio.
